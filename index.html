LCEAS 國立東華大學學習關懷預警系統 National Dong Hwa University Learning Care Early Alert System

使用說明

安安是 LCEAS 中的 AI 學習陪伴，協助整理課業、時間安排、學習策略與求助表達。

請用自己的節奏輸入想談的學習狀況，也請避免輸入身分證字號、完整住址、金融資訊等不必要的敏感資料。

安安提供學習上的陪伴與引導，不取代校內專業諮詢或正式課業評量。

連線設定

OpenAI API key 請放在 Apps Script 的 Script Properties：OPENAI_API_KEY，也支援 API_KEY。
