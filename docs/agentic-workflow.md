# 學習陪伴 Agentic Workflow

本系統的 agent 不是替學生下結論，而是協助學生把「我好像學不會」拆成可處理的訊號，再把需要教師介入的部分整理成可追蹤的紀錄。

## 1. 聆聽

先讓學生用自己的話描述最近卡住的地方。系統只追問必要資訊：課程、任務、時間壓力、已嘗試方法，以及希望得到的支持。

## 2. 釐清

把學生的敘述整理成幾個常見面向：

- 概念理解：聽得懂片段，但無法連成完整解法。
- 學習策略：花很多時間，方法卻沒有帶來進展。
- 時間管理：作業、考試、打工或社團壓力互相擠壓。
- 參與狀態：缺課、遲交、無法跟上課程節奏。
- 情緒與信心：焦慮、挫折、逃避或不敢求助。
- 學習背景差異：先備知識、語言、跨域修課或轉銜落差。

## 3. 辨識

系統依據自評量表、文字訊號、期限壓力與參與狀態產生風險層級：

- 穩定：目前有困難，但學生能說出下一步。
- 觀察：困難持續出現，需要一週內追蹤。
- 優先關懷：出現多重壓力或課業表現明顯下滑，需要導師或授課教師介入。
- 立即轉介：出現自我傷害、重大危機或無法維持安全的訊號，需立即聯絡校安、諮商或緊急資源。

## 4. 建議

每次回應只給 1 到 3 個可執行步驟，避免把學生推向更多壓力。例如：

- 今天先整理三個最不懂的題目，明天帶去問助教。
- 把期中考範圍拆成兩段，先處理最可能得分的單元。
- 寫信給授課教師，說明目前卡住的地方與已嘗試的方法。

## 5. 追蹤

學生送出紀錄後，系統寫入 Google Sheet，並建立追蹤日期。教師端看到的是摘要、風險原因與建議行動，不需要閱讀學生完整私密對話。

## 6. 轉介

當學習困難已超出課業支持範圍，系統提醒學生聯絡合適單位，並讓教師端標記轉介狀態。此流程不取代心理諮商、醫療或校安處置。
