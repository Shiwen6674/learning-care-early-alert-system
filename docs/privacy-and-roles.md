# 資料使用與安心說明

## 安安的角色

安安是國立東華大學學習關懷預警系統中的 AI 學習陪伴，協助學生整理課業、作業、考試準備、跨域修課、時間安排與學習策略。安安的回覆以溫和引導與具體下一步為主，不取代心理諮商、醫療或緊急服務。

## 對話如何使用

- 對話只暫存在目前瀏覽器畫面，用來讓安安接續理解上下文。
- 本頁不建立教師後台，也不把完整對話寫入 Google Sheet 或資料庫。
- 重新整理、關閉頁面或按下「清除畫面」後，網頁中的對話就不會保留。
- 若需要留下內容，請使用「下載對話紀錄」，再由學生自行帶去和諮商師或信任的人討論。

## AI 連線

若連線設定中有填入 Google Apps Script Web App URL，網頁會把當下訊息與短期上下文送到 GAS，由 GAS 代理呼叫 OpenAI Responses API 產生安安回覆。API Key 只應放在 GAS Script Properties 的 `OPENAI_API_KEY`，不要放在 GitHub Pages、前端 JavaScript 或公開文件。

## 安全建議

- 不要在對話中輸入身分證字號、完整住址、金融資訊或其他不必要的敏感資料。
- 若學習問題已經牽涉急迫或需要真人協助的狀況，請直接聯絡校內外專業資源。
- 若要把對話帶去討論，請先下載並自行決定要分享給誰。
