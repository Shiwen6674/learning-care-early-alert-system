# 資料使用與安心說明

## 安安的角色

安安是國立東華大學學習關懷預警系統中的 AI 學習陪伴，協助學生整理課業、作業、考試準備、跨域修課、時間安排與學習策略。安安的回覆以溫和引導與具體下一步為主，不取代校內專業諮詢或正式課業評量。

## 資料如何處理

- 本頁不建立教師後台，也不把完整內容寫入 Google Sheet 或資料庫。
- 頁面上的訊息用於當次 AI 回應脈絡。
- 使用者可以自行下載本次文字檔。

## AI 連線

若連線設定中有填入 Google Apps Script Web App URL，網頁會把當下訊息與短期上下文送到 GAS，由 GAS 代理呼叫 OpenAI Responses API 產生安安回覆。API Key 只應放在 GAS Script Properties 的 `OPENAI_API_KEY` 或 `API_KEY`，不要放在 GitHub Pages、前端 JavaScript 或公開文件。

## 安全建議

- 不要在對話中輸入身分證字號、完整住址、金融資訊或其他不必要的敏感資料。
- 若學習問題已經牽涉急迫或需要真人協助的狀況，請直接聯絡校內外專業資源。
