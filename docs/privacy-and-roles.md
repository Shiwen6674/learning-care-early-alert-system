# 角色權限與資料保護

## 角色

- 學生：可建立自己的學習近況、對話摘要、自評紀錄與追蹤目標。
- 教師：可查看自己授權範圍內的學生摘要、風險層級、教師紀錄與追蹤事項。
- 院系承辦或管理者：可查看彙整統計與跨系所預警訊號，不應直接瀏覽不必要的完整對話。

## 資料最小化

建議只保存學習輔導必要資料：

- 身分：姓名、信箱、學號或教師代碼、學院、系所、年級。
- 學習訊號：課程名稱、困難類型、自評分數、期限壓力、摘要與建議行動。
- 追蹤紀錄：教師備註、下一次關懷時間、轉介狀態。

不建議保存完整敏感敘事；若需保存，應明確取得同意，並限制教師端顯示範圍。

## 安全建議

- GitHub Pages 僅放公開前端，不放 API key、教師密碼或管理者 token。
- Google Apps Script 使用 Script Properties 保存 `ADMIN_SHARED_SECRET`、`OPENAI_API_KEY`。
- 教師端查詢需由 GAS 驗證 token、教師信箱與授權範圍。
- 若學校有 Google Workspace，正式版應改用 OAuth / SSO。
- 任何自傷、傷人或立即危險訊號，應引導學生立刻聯絡校安、119/110 或校內諮商資源。
